# 작은회사 열기

사무실은 `http://127.0.0.1:4780/`에서 실행되는 로컬 관찰 화면입니다.

사용자가 사무실을 열어달라고 하면 Codex의 `open_in_codex` 도구로 위 주소를 엽니다.
연결 상태는 `http://127.0.0.1:4780/api/health`에서 읽기 전용으로 확인합니다.
수신기가 꺼져 있으면 이 플러그인의 `README.md`에 있는 실행 안내를 확인합니다.
사용자가 복제한 Agent Office 저장소에서 `npm ci`, `npm run build`, `node scripts/runtime.mjs`로 시작할 수 있습니다.
설치 캐시는 실행 저장소가 아닐 수 있으므로 저장소 위치를 추측하지 않습니다.

이 플러그인은 작업 상태 메타데이터를 HTTP 수신기에 보냅니다. 원래 작업을 실행·중단·승인하지 않습니다.
실제 이벤트에 없는 모델이나 승인 결과를 추측하지 않습니다. 미확인 정보는 확인 불가로 설명합니다.
플러그인 설치 여부, hook 신뢰 여부, 수신기 실행 여부, 실제 이벤트 수신 여부를 별도로 확인합니다.
