# Agent Office 아이콘 비교

`index.html`을 브라우저에서 열면 됩니다. 서버·외부 폰트·외부 네트워크가 필요 없습니다.

- 01~06 시안을 큰 이미지와 32·64 CSS px 크기로 비교합니다. 화면 폭에 따라 3열·2열·1열로 바뀝니다.
- 이미지를 누르면 확대해서 볼 수 있습니다. ←·→ 키로 이동하고 Esc로 닫습니다.
- 밝은·어두운 바탕을 바꾸고, 시안을 선택한 뒤 전달할 문장을 복사할 수 있습니다. 파일 열기 환경에서 자동 복사가 제한되면 선택된 문장을 복사 단축키로 복사합니다.
- 선택은 현재 화면의 강조 표시입니다. 앱 아이콘이나 원본 PNG를 변경하지 않으며 새로고침하면 해제됩니다.

현재 파일은 1254 × 1254 PNG 시안입니다. 작은 미리보기에도 원본의 흰 여백이 포함됩니다. 선택 후 투명 여백 정리와 1024px 정리본·macOS ICNS 제작을 진행할 예정입니다.
