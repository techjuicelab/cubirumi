# 세 층 회사 아이콘 · 색상 비교

선택한 세 층 회사의 건물 형태, AI 직원, 책상, 구도는 유지하고 색상 조합을 다듬는 시안입니다.

| 시안 | 프레임과 바탕 | 실내 조명 | 분위기 |
| --- | --- | --- | --- |
| A · 크림·세이지 | 아이보리 `#F0EDE3`, 세이지 `#668179` | 린넨 `#E9DEC4` | 따뜻한 미니어처 |
| B · 네이비·앰버 | 네이비 `#162737`, 블루슬레이트 `#355467` | 앰버 `#EFD89A` | 불 켜진 회사 |
| C · 화이트·스카이블루 | 스카이블루 `#D9E9F3`, 포슬린 `#F0F3F5` | 아이보리 `#FFF0D4` | 밝고 차분한 사무실 |

`index.html`에서 원본과 비교하거나 32px·64px 크기로 확인할 수 있습니다. 색상 코드는 생성 방향을 지정하는 참고값이며 모든 픽셀을 동일한 코드로 제한하지는 않습니다.

내장 이미지 생성 도구의 원본 참조 편집으로 제작합니다. 전체 편집 프롬프트는 `prompts.json`에 있습니다. 원본과 설치된 앱 아이콘은 보존하며, 최종 색상을 고른 다음 투명 여백·아이콘 크기·ICNS를 마무리합니다.
