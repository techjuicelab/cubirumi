# Cubirumi (큐비루미)

Codex와 Claude Code의 작업을 귀여운 미니어처 사무실로 보여주는 로컬 오픈소스 앱입니다. 프로젝트는 층, 채팅은 작업구역, 에이전트는 직원이 됩니다. 화면과 안내는 현재 한국어입니다.

## 무엇을 볼 수 있나요?

- 화면 전체를 사용하는 Three.js 사무실과 프로젝트 층 전환
- 실제 직원과 하위 에이전트의 명찰·실행 모델·업무 상태
- 좌석마다 다른 실루엣(머리·의상·소품)과 상태에 따라 바뀌는 표정, 타이핑·페이지 넘김·기지개 같은 작은 동작
- 움직이는 직원을 따라가는 현재 업무 말풍선
- 작업 상태에 따른 캐릭터 행동과 마지막 도구 사용 기록
- 코드 조립·문서 출력과 정리·검색 드론 등 업무별 3D 소품, 작업 중인 직원의 밝은 빨간 표시와 오류·승인 표시
- 관측된 업무 지시·승인 요청과 실제 직원 간 전달을 표현하는 작은 종이비행기
- 채팅별 사무실, 직원 수에 맞춰 늘어나는 좌석과 자동 관찰 자동 순회
- 별도로 구획한 사장실과 실제 승인 요청에 따른 직원 방문·복귀
- 360도 회전·확대·축소·이동, 일하는 직원을 천천히 따라가는 카메라와 30fps 절전 화면
- Codex·Claude Code 공용 에너지: 공식 사용 한도의 사용률·잔여량·초기화 시각
- 설정 패널, 현재 연결된 모델의 도구·전달·응답 종료 기록, 회사명·사장 이름 개인 설정
- 재시작 후 복원되는 로컬 업무 기록
- 주소창 없는 macOS 독립 앱과 항상 위에 표시

웹 화면은 관찰용입니다. 업무 지시와 승인은 평소 사용하는 AI 앱에서 합니다. 시각화 자체는 AI 모델을 호출하지 않습니다. Codex 앱에 설치하는 플러그인과 옆에 띄우는 로컬 웹 화면으로 구성되며, AI 앱의 원래 UI를 수정하지 않습니다.

## macOS 앱 다운로드

다운로드판은 `.app` 안에 Node.js와 사무실 서버, 웹 화면을 함께 포함합니다. 사용자는 Node.js·npm·저장소를 설치하지 않고 앱을 실행할 수 있습니다. macOS **13.5 이상**을 대상으로 하며 Apple Silicon은 `arm64`, Intel Mac은 `x64` ZIP을 사용합니다.

[GitHub Releases](https://github.com/techjuicelab/cubirumi/releases)에서 Mac에 맞는 ZIP을 내려받아 풀고 `Cubirumi.app`을 응용 프로그램 폴더에 옮깁니다. 서명된 자동 업데이트를 지원합니다. 첫 실행 허용, 업데이트와 기존 개발 설치에서의 전환은 [macOS 설치 안내](docs/DESKTOP.md)를 참고하세요. 초기 공개판이며 신규 Mac의 Gatekeeper 첫 실행과 실제 제품의 버전 간 업데이트는 추가 검증이 필요합니다.

## 소스에서 빠른 시작

Node.js **22.18 이상**과 npm이 필요합니다. GitHub에서 저장소를 clone하거나 ZIP으로 내려받아 압축을 푼 뒤 실행합니다.

```sh
cd cubirumi
npm ci
npm run build
npm start
```

**http://127.0.0.1:4780** 을 엽니다. 실행 중인 로컬 Codex 기록이 있으면 자동으로 관측을 시도합니다. Codex가 설치되어 있지 않아도 웹 화면과 Claude Code 이벤트 수신기를 사용할 수 있습니다. 종료는 터미널의 `Ctrl+C`입니다.

처음부터 실제 연결된 사무실이 전체 화면에 나타납니다. 왼쪽 층 버튼으로 프로젝트를 선택하면 같은 프로젝트의 여러 채팅에 연결된 직원을 함께 봅니다. 사무실 이름 아래 선택창으로 특정 채팅만 볼 수도 있습니다. 종료·퇴근한 직원과 시연 직원은 표시하지 않습니다. 실제 연결이 없으면 출근 대기 화면이 나타납니다.

작업 중인 직원은 밝은 빨간 링과 머리 위 표식으로 강조합니다. 대기 직원의 캐릭터·명찰·말풍선과 사용하지 않는 책상은 숨기고, 현재 활동 인원에 맞춰 사무실 크기도 줄입니다. 직원 기록과 프로젝트 층은 유지합니다. 전체 직원 목록에서 대기 직원을 선택하거나 실제 전달을 재생할 때는 필요한 자리만 잠시 표시합니다. 활동 목록은 작업·승인·오류 상태를 보여주며, 대기 직원은 전체 직원 목록에서 확인할 수 있습니다. 응답이 끝났다는 이유만으로 세션 종료나 퇴근으로 기록하지 않습니다.

하단 **자동 관찰** 또는 `C`를 눌러야 자동 회전·업무 추적·순회가 시작되며, `Esc`로 종료합니다. 설정에서 관찰 중의 순회 간격·업무 추적·자동 회전과 명찰·동작 줄이기·절전을 조절합니다. 휠이나 두 손가락으로 확대·축소하고, 드래그로 회전하며, `Shift`+드래그 또는 두 손가락 이동으로 화면을 옮깁니다. 층이나 직원을 직접 선택하거나 카메라를 조작하면 자동 관찰가 종료되고 선택한 화면을 유지합니다. 다른 앱으로 포커스를 옮기거나 돌아와도 자동 관찰가 켜지지 않습니다. 다시 자동으로 둘러보려면 **자동 관찰** 또는 `C`를 누릅니다.

에너지 탱크는 자동 관찰에서도 남아 있습니다. 누르면 시간대별 한도를 펼쳐봅니다. 직원 개인의 체력이나 성과 점수가 아니라 계정에서 공유하는 사용 한도입니다. 수치를 받지 못했으면 미확인으로 표시하고, 오래된 수치는 관측 시각과 함께 흐리게 남겨 두되 현재 값으로 취급하지 않으며, 초기화 시각이 지났다고 자동으로 100%를 채우지 않습니다. [사용량 연결과 한계](docs/USAGE.md)

Claude Code를 연결하려면 저장소에서 `node scripts/install-claude.mjs install`을 실행한 뒤 새 터미널 Code 세션을 시작하세요. 기존 플러그인·표시줄 설정을 보존합니다. [설치 안내와 붙여 넣을 프롬프트](docs/CLAUDE_SETUP_PROMPT.md)

층을 누르면 그 층의 사무실을, 직원을 누르면 해당 직원을 가까이에서 봅니다. **건물 전체 보기**는 자동 순회를 시작하지 않고 전체 건물 전경으로 이동합니다. 자동 관찰를 직접 켠 동안에는 일하는 직원 수와 마지막 방문 시점을 함께 고려해 활동이 있는 층과 작업구역만 둘러봅니다. 수동으로 선택했던 층과 관계없이 건물 전체의 현재 활동을 기준으로 순회하며, 활동이 없는 구역은 자동 방문하지 않습니다. 말풍선은 설정에서 끌 수 있습니다.

소스 개발용 macOS 창을 설치하려면 `npm run desktop:install`을 실행합니다. 이 명령으로 만드는 창은 별도 로컬 서버에 연결합니다. Node.js·서버를 포함하는 다운로드판은 `npm run desktop:package`로 만듭니다. [앱 설치와 조작](docs/DESKTOP.md) · [Claude 실제 연결 확인 프롬프트](docs/CLAUDE_VERIFY_PROMPT.md)

### 회사명과 사장 이름 바꾸기

**설정 → 우리 회사와 사장님**에서 회사 이름과 사장님 이름을 입력하고 **이름 저장**을 누릅니다. 회사 간판과 사장 명찰에 바로 반영되며 앱을 다시 열어도 유지됩니다. 공개 기본값은 회사명 `나의 회사`, 사장 이름 `나`입니다.

터미널에서는 회사명만 바꿀 수도 있습니다. 저장된 사장 이름은 유지됩니다.

```sh
npm run company -- "나의 스튜디오"
```

터미널에서 변경했다면 화면을 새로고침합니다. 두 이름은 이 컴퓨터의 사용자 데이터 폴더에 저장되며 Git 저장소나 빌드 파일에 들어가지 않습니다.

### 소스 실행용 macOS 로그인 자동 실행

빌드를 완료한 뒤 실행합니다. 현재 사용하는 Node.js와 저장소의 위치를 해당 사용자의 LaunchAgent에 등록합니다.

```sh
node scripts/install-runtime.mjs install
node scripts/install-runtime.mjs status
```

저장소나 Node.js를 옮기려면 기존 위치에서 서비스를 제거한 뒤 새 위치에서 설치하세요. `stop`은 현재 세션만 중지하므로 자동 실행 등록 파일도 따로 제거해야 합니다. 수동 `npm start`와 자동 실행 서비스를 동시에 켜지 않습니다. 다운로드판은 앱이 자체 서버를 시작하므로 이 LaunchAgent가 필요하지 않습니다. 실행·중지 방법은 [설치 안내](docs/INTEGRATIONS.md)를 참고하세요.

## 연결 범위

| 환경 | 현재 연결 |
| --- | --- |
| Codex Desktop / CLI 로컬 작업 | 실험적인 읽기 전용 실행 기록 관측. 직접 보고된 모델과 상태만 표시 |
| Codex hooks 지원 환경 | 동봉 플러그인으로 lifecycle 이벤트 전송. 설치와 hook 신뢰 검토 필요 |
| Claude Code CLI | 사용자 플러그인으로 상태 이벤트 전송, 공식 statusline 입력으로 지원 계정의 사용 한도 전송 |
| Claude Desktop 로컬 Code 세션 | 공유 플러그인·hooks 설정 지원. Desktop Code 세션에서는 statusline 명령 호출이 관찰되지 않아 사용량이 연결되지 않음. 터미널 CLI 세션을 함께 열면 그 세션의 statusline이 같은 계정의 사용 한도를 전송함 |
| 일반 Claude Chat / Cowork | 전체 활동 관측 미지원 |
| 원격 호스트·클라우드에서 실행되는 작업 | 해당 호스트의 별도 연결 없이는 관측 불가 |

macOS에서 실제 연결을 확인했습니다. Linux의 기본 웹 서버와 읽기 전용 관측기는 호환을 목표로 하며 GitHub CI에 Linux/macOS 테스트를 포함합니다. Windows 전체 동작은 아직 검증하지 않았습니다.

## 관측의 의미

업무별 장면과 전환·관측 기준은 [업무 애니메이션](docs/ACTIVITY_ANIMATIONS.md)을 참고하세요. 실제 도구 사용에서 확인한 업무 종류를 표현하며, 새 장면은 기존 캐릭터와 사무실 디자인 위에 추가됩니다.

- **보고된 모델만 표시합니다.** 부모 모델·설정 기본값을 자식의 실행 모델로 추정하지 않습니다. Claude Code hook에서 모델이 누락되면 해당 직원 자신의 로컬 실행 기록으로 보완합니다. 이미 연결된 직원도 10초마다 확인하며, 직원·세션·시각이 일치하는 근거가 없으면 미확인으로 남습니다. 모델 정보의 보정은 직원의 업무 상태·진행률·활동 건수를 바꾸지 않습니다.
- **응답 종료는 전체 업무 완료가 아닙니다.** 직원은 대기하고, 명시적인 종료 이벤트가 있을 때만 퇴근합니다.
- **애니메이션은 상태를 표현합니다.** 비공개 사고 과정, 타이핑 내용, 정확한 진행률을 보여주는 기능은 아닙니다. 대기 직원은 장면에서 숨기며, 활동 중의 동작은 일시정지와 동작 줄이기 설정을 따릅니다.
- **서류 전달·승인 완료에는 근거가 필요합니다.** 단순 실행 순서나 도구 재개로 전달·승인을 만들어내지 않습니다. 현재 Codex 기록에서 성공 여부가 확인되지 않는 이벤트는 표시하지 않습니다.
- **종이비행기는 관측된 통신을 표현합니다.** 직원 간 전달은 실제 양쪽 컴퓨터를 연결하며, 다른 층·작업구역 사이의 전달은 건물 전경에서도 볼 수 있습니다. 일반 메시지는 해당 컴퓨터 주변의 짧은 비행으로, 사용자 입력은 현재 실내에 표시된 직원에게 사장 컴퓨터에서 보내는 비행으로 구분합니다. 없는 직원을 만들지 않으며 동시 비행은 최대 32개입니다. 실제 승인 요청은 직원의 사장실 방문으로 구분합니다.
- Codex 로컬 SQLite/JSONL과 Claude 로컬 JSONL 관측은 **내부 형식에 의존하는 실험적 연결**입니다. 앱 업데이트로 수정이 필요할 수 있습니다. 연결 방식과 한계는 [연결 안내](docs/INTEGRATIONS.md)에 있습니다.

## 개인정보와 로컬 저장

프롬프트·코드·도구 인수·결과 원문은 자동 전송하거나 저장하지 않습니다. 프로젝트 폴더명·직원 별칭·모델·작업 상태·연결 관계는 로컬 메타데이터로 저장됩니다. DB의 최초 프롬프트가 들어갈 수 있는 제목 필드는 읽지 않습니다. Claude Code hook은 실행 모델을 알기 위해 해당 세션·하위 에이전트의 로컬 트랜스크립트 파일 끝부분을 읽지만, 모델 식별자 외의 내용은 전송·저장·기록하지 않습니다.

기본 저장 위치는 macOS의 `~/Library/Application Support/AgentOffice`, 그 외 환경의 `~/.local/share/agent-office`입니다. `AGENT_OFFICE_DATA_DIR`로 바꿀 수 있습니다. 회사명·사장 이름 설정과 기록은 Git과 배포 번들에서 제외됩니다. 최대 5,000개 이벤트와 512명 직원 상태를 보관하고 최초 로딩은 최근 200건을 불러오며 열린 화면은 최대 500건을 유지합니다. 소통 패널은 선택한 필터의 최근 100건을 표시합니다.

## 개발과 기여

```sh
npm run dev
npm test
npm run build
```

`npm run dev`는 개발 UI 5173과 이벤트 수신기 4780을 실행합니다. 자동 실행 서비스가 이미 켜져 있다면 `npm run web`으로 UI만 실행하세요. 변경을 stage 한 뒤 `npm run check:public`으로 공개 파일을 검사할 수 있습니다.

기여와 버그 제보는 [CONTRIBUTING.md](CONTRIBUTING.md), 다운로드판 빌드·업데이트 서명은 [릴리스 안내](docs/RELEASING.md)를 참고하세요. 실제 대화, 작업 기록, 개인 회사명과 경로가 보이는 화면을 공개 이슈에 올리지 마세요.
