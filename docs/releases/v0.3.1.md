# Cubirumi v0.3.1

오래 사용하지 않은 프로젝트 층을 숨기는 기능을 공개 다운로드판에 포함했습니다. v0.3.0 다운로드판에는 없던 기능입니다.

## 바뀐 화면

- 기본값은 **한 시간 동안 새 소식이 없는 층을 숨기고, 최근에 소식이 온 층부터 최대 8개**를 보여줍니다.
- 현재 화면에서 작업·확인 요청·오류가 표시되는 층은 기간과 층수 제한에 관계없이 표시합니다. 확인이 필요한 층이 많으면 8층을 넘을 수 있습니다.
- 숨긴 층 수는 층 목록 아래에 표시합니다. 해당 프로젝트에 새 소식이 오면 층이 다시 나타납니다.
- **설정 → 오래 쉰 층 숨기기**에서 30분~7일 또는 숨기지 않음, **건물 최대 층수**에서 4·6·8·10·12층 또는 제한 없음을 선택할 수 있습니다.

## 기록과 설정 보존

층 숨기기는 화면에 표시할 층만 고릅니다. 관측 기록을 삭제하거나 직원의 세션을 종료·퇴근으로 바꾸지 않습니다.

회사명·사장 이름과 관측 기록은 기존 `~/Library/Application Support/AgentOffice`에 보관합니다. 앱을 업데이트해도 이 데이터 폴더를 교체하거나 삭제하지 않습니다. 기존 창 설정과 자동 업데이트 선택도 유지합니다.

## 업데이트 적용 시점

공개 다운로드판은 Sparkle로 업데이트를 확인합니다. 자동 확인과 자동 다운로드가 켜져 있으면 준비된 업데이트를 **앱 종료 시 설치**합니다. 창만 닫으면 앱은 계속 실행되므로, `⌘Q`로 종료한 뒤 다시 열어 새 버전을 확인하세요. **앱 메뉴 → 업데이트 확인…**에서 직접 확인할 수도 있습니다. 자동 확인과 자동 다운로드는 기본값이며 기존에 바꾼 선택은 유지합니다.

자동 업데이트 메뉴가 비활성화된 개발용 창이나 로컬 검증 빌드는 [GitHub Releases](https://github.com/techjuicelab/cubirumi/releases/latest)에서 자신의 Mac에 맞는 `arm64` 또는 `x64` ZIP을 받아 설치하세요. 별도 소스 서버를 사용했다면 먼저 [기존 소스 설치에서 전환](https://github.com/techjuicelab/cubirumi/blob/main/docs/DESKTOP.md#기존-소스-설치에서-전환)을 확인하세요. `git pull`만으로 이미 설치한 앱이 업데이트되지는 않습니다.

## 기존 설치 확인

1. Finder에서 설치한 `Cubirumi.app`을 직접 열고 **앱 메뉴 → Cubirumi에 관하여**에서 `0.3.1`인지 확인합니다.
2. 앱 설정에 **오래 쉰 층 숨기기**와 **건물 최대 층수**가 있는지 확인합니다.
3. 예전 화면이 계속 열리면 Dock에서 앱을 우클릭한 뒤 **옵션 → Finder에서 보기**로 경로를 확인합니다. `/Applications`뿐 아니라 `~/Applications`, 다운로드 폴더, 개발용 빌드 폴더의 앱이 별도로 열릴 수 있습니다.

## 출시 검증

Linux·macOS의 Node 22·24 검증과 전체 583개 테스트를 통과했습니다. Apple Silicon·Intel 배포 파일의 익명 다운로드, 체크섬, ZIP·업데이트 피드 서명, 내장 앱 구성을 확인했습니다.

Apple Silicon Mac에서 공개 피드를 통한 v0.3.0 → v0.3.1 업데이트와 새 버전 재실행을 확인했습니다. 설치된 앱은 공개 배포 파일과 일치하며 기존 설정·기록 저장소와 자동 업데이트 선택도 유지됐습니다.

신규 Mac의 Gatekeeper 첫 실행과 실제 Intel Mac에서의 동작은 별도 검증이 필요합니다. 현재 배포판은 Apple Developer ID 서명·공증을 제공하지 않습니다. [설치와 보안 확인 안내](https://github.com/techjuicelab/cubirumi/blob/main/docs/DESKTOP.md#다운로드판-설치)
