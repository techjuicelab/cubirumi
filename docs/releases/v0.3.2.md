# Cubirumi v0.3.2

Cubirumi now opens in English and lets you switch to Korean in Settings. This release also includes activity-monitoring corrections and macOS window fixes made since v0.3.1.

## English and Korean

- Open **Settings → Language** and choose **English** or **한국어**. The interface changes immediately, including status labels, usage explanations, dates, and accessibility text.
- Your choice is saved on this device and restored after a restart. Other office windows and the app's macOS menus follow the same language.
- The macOS app menu also offers **Language → English / 한국어**.
- Company names, project names, agent aliases, and original activity records keep their text. Switching the interface language does not rename or rewrite them.

## Monitoring and window fixes

- Recover the employee list after an initial state request fails, and preserve live updates while retrying.
- Recover explicitly completed Codex turns after an observer restart, and discover newer Claude conversations when many local logs exist.
- Keep the original observation time for older Claude usage readings rather than presenting them as fresh.
- Clear completed tool calls at the appropriate lifecycle boundary, count tool starts consistently, and avoid attributing activity from an earlier task to the current model.
- Avoid carrying an old chat title into a new session.
- Enable fullscreen controls and independent observation windows in the macOS app.
- Update the development dependency `source-map-js` to 1.2.2 to address its reported vulnerability.

## Download or update

Download the ZIP for your Mac from [GitHub Releases](https://github.com/techjuicelab/cubirumi/releases/latest):

- **Apple Silicon:** `Cubirumi-0.3.2-macos-arm64.zip`
- **Intel:** `Cubirumi-0.3.2-macos-x64.zip`

Both packages require **macOS 13.5 or later** and include the local runtime; no separate Node.js installation is needed.

Existing public app installations can use **Cubirumi → Check for Updates…** (or **업데이트 확인…** in Korean). The existing Sparkle update feed and signing key are retained. If automatic downloads are enabled, a downloaded update installs when you quit the app with `⌘Q`; closing the window alone leaves the app running. Reopen the app and check **About Cubirumi** for version `0.3.2`.

Existing local settings, company and owner names, and retained activity records are preserved. The normal local history retention limit still applies as new activity arrives. For a manual replacement, quit the old app before replacing `Cubirumi.app`. See the [installation guide](https://github.com/techjuicelab/cubirumi/blob/main/docs/DESKTOP.md) for first-open instructions and migration from a source installation.

## Validation

The feature source passed all **632 tests**, followed by **111 UI and language checks** after the final UI adjustment. The web and macOS package builds passed. A local Apple Silicon installation was also checked for English/Korean switching, menu and observation-window synchronization, restart persistence, and preservation of existing settings and records.

Those installed-app checks used a local package carrying the new feature source before the public version was raised to v0.3.2. Public v0.3.2 artifact and update checks are recorded separately when completed. A fresh Mac's Gatekeeper first launch and operation on physical Intel hardware still require separate validation. This release does not provide Apple Developer ID signing or notarization.

## 한국어 안내

기본 화면은 영어입니다. **Settings → Language → 한국어**에서 한국어로 바꾸고, **설정 → 언어 → English**에서 영어로 돌아갈 수 있습니다. 선택은 재실행 후에도 유지되며 다른 사무실 창과 macOS 메뉴에도 반영됩니다. 회사명·프로젝트명·직원 별칭·기록 원문은 바꾸지 않습니다.

v0.3.1 이후의 관측 복구·사용량 시각·도구 집계·모델 귀속·채팅 제목 오류와 macOS 전체 화면·독립 관찰 창 문제도 함께 수정했습니다. Apple Silicon은 `arm64`, Intel은 `x64` ZIP을 받으세요. macOS 13.5 이상이 필요합니다.

기존 공개 앱은 **Cubirumi → 업데이트 확인…**으로 업데이트할 수 있습니다. 자동 다운로드를 켰다면 `⌘Q`로 종료한 뒤 다시 열어 적용하고, **Cubirumi에 관하여**에서 `0.3.2`를 확인하세요. 기존 설정·이름·보관 기록은 유지되며, 새 활동이 쌓일 때 적용되는 기존 기록 보관 한도도 같습니다.
